교육용 화면 안내
기획국 화면을 기준으로 설명합니다. 심사부서명은 실제 명칭이며, 이름·담당 배정·입력 결과·평가는 교육용 예시입니다. 각 캡처의 출원번호와 가명은 화면별로 다를 수 있습니다. 현재 사이트의 등록 인원과 진행 상태는 캡처와 다를 수 있습니다.
01

소속 심사국에서 본인 선택

심사국 주소로 접속한 뒤 본인의 소속과 이름을 누릅니다.

  1. 기획국 예시 주소: https://patent-examiner-mvp.sohnjun96.workers.dev/기획국
  2. 공지사항을 확인하고 심사관 선택에서 본인을 누릅니다.
  3. 왼쪽 아래의 이름과 소속을 확인합니다. 다른 사용자가 선택되어 있으면 로그아웃 후 다시 선택합니다.

별도의 아이디·비밀번호 입력 화면은 없습니다.

이름이 없거나 선택할 수 있는 심사관이 없습니다가 표시되면 관리자에게 심사관 등록을 요청합니다.

화면은 2026-10-31에 캡처한 교육용 예시입니다. 이름·배정·입력 문헌·평가는 예시이며, 현재 기획국의 실제 사용자 목록과 다를 수 있습니다.

02

운영월과 진행 단계 확인

내 심사 업무의 오른쪽 위에서 운영월을 선택합니다.

  1. 업무를 수행할 운영월을 선택합니다.
  2. 업무 일정에서 대상 건 선정·AI 검색 결과 입력·평가의 상태를 확인합니다.
  3. 대상 출원을 등록하려면 대상 건 선정이 진행, 평가하려면 평가가 진행이어야 합니다.

시작 전·중지·마감 상태의 단계는 입력할 수 없습니다. 관리자에게 해당 단계의 진행 전환을 요청합니다.

기한은 안내용입니다. 날짜가 지났다는 이유만으로 자동 마감하지 않습니다.

캡처의 운영월·기한·남은 일수는 촬영 당시의 예시입니다. 실제 업무 화면에 표시된 내용을 확인합니다.

03

대상 출원 입력·수정

대상 건 선정에서 출원 추가를 누릅니다.

  1. 출원번호를 앞자리 2자리·연도 4자리·일련번호로 나누어 입력합니다. 전체 번호를 붙여 넣을 수도 있습니다.
  2. CPC를 입력하고 선행기술조사 보고서의 있음·없음을 실제 보유 여부에 맞게 선택합니다.
  3. 새 행은 추가, 기존 행은 저장을 누릅니다. 수정·삭제도 해당 행에서 처리합니다.
  4. 자동 임시저장됨을 확인합니다. 편집을 끝내려면 행의 추가·저장 또는 취소를 먼저 누릅니다.

출원번호 형식 예시: 10 / 2021 / 0013789. 특허는 10, 실용신안은 20으로 시작합니다.

CPC는 선택 입력입니다. 새 출원은 보고서 없음으로 시작하므로 실제 보유 여부를 확인합니다.

행의 추가·저장·삭제는 목록 전체를 자동 저장합니다. 확정 전 목록은 AI 담당자에게 공개되지 않습니다.

캡처는 기존 행을 수정하는 모습입니다. 현재 화면에는 작업 후 자동 저장 상태도 표시됩니다.

04

선정 확정과 제출 목록 수정

목록을 확인한 뒤 선정 확정을 눌러 AI 담당자에게 공개합니다.

  1. 등록한 출원번호와 보고서 유무를 확인합니다.
  2. 선정 확정을 누르고 확인창에서 확정합니다.
  3. 평가 단계가 진행이면 내 평가 대상 건에 확정된 출원이 표시됩니다.
  4. 선정 단계가 진행 중이면 제출 목록 수정에서 고칠 수 있습니다. 행을 저장한 뒤 수정 사항 저장으로 목록 화면으로 돌아갑니다.

임시저장만 한 목록은 AI 담당자에게 공개되지 않습니다.

이미 확정한 목록의 행을 추가·저장·삭제하면 확정 상태를 유지한 채 변경 내용이 자동 반영됩니다.

평가 단계가 시작되지 않았으면 제출한 출원 목록이 표시됩니다.

05

공개된 검색 결과 열기

내 평가 대상 건에서 평가 입력을 누릅니다.

  1. AI 검색 문헌 열에서 공개된 AI별 문헌 수를 확인합니다.
  2. 해당 출원의 평가 입력 또는 출원번호를 누릅니다. 평가 화면이 새 창으로 열립니다.
  3. AI 탭과 왼쪽 문헌 목록을 선택해 문헌별 보고서를 확인합니다.
  4. 원문 열기로 원문을 확인합니다. 비특허문헌은 서지정보도 확인합니다.

입력 대기는 AI 결과가 아직 공개되지 않은 상태입니다.

모든 AI가 공개를 마치지 않아도 공개된 결과에 대한 평가를 완료할 수 있습니다.

06

문헌 점수와 인용 여부 입력

공개된 모든 문헌에 점수와 인용 여부를 입력합니다.

  1. 이 문헌 평가에서 문헌 점수 0~5점을 선택합니다.
  2. 인용 O 또는 미인용 X를 선택합니다. 문헌별 피드백은 선택 입력입니다.
  3. 다음 문헌을 누르거나 왼쪽 목록에서 다른 문헌을 선택해 반복합니다.
  4. 모든 문헌 평가 완료를 확인하고 평가 결과 보기를 누릅니다.

3점의 기준은 평균적인 선행기술조사 보고서 수준입니다.

중간에 멈추려면 임시저장을 누릅니다. 평가 입력은 AI 초안처럼 자동 저장되지 않습니다.

캡처의 점수와 인용 여부는 사용법 설명용이며 실제 관련성 판단이 아닙니다.

07

검색 품질 순위와 평가 종료

문헌 평가 결과를 확인하고 조사 방식별 검색 품질 순위를 입력합니다.

  1. 문헌 평가 결과 표에서 점수와 인용 여부를 확인합니다.
  2. 비교할 조사 방식에 동순위 없이 순위를 선택합니다. 이미 선택된 순위를 누르면 두 방식의 순위가 바뀝니다.
  3. 비교하지 않을 방식만 평가 제외로 선택합니다. 출원 건 관련 피드백은 선택 입력입니다.
  4. 순위 선택 완료를 확인한 뒤 평가 종료를 누릅니다.

보고서 있음인 출원은 AI 결과와 선행기술조사 보고서를 함께 비교합니다. 없음이면 AI 방식끼리 비교합니다.

비교할 방식이 1개면 비교 불가, 2~3개면 1위부터 차례로 선택합니다. 4개 이상이면 상위 3개는 1~3위, 나머지는 순위 외를 선택합니다.

임시저장과 평가 결과 보기는 최종 완료가 아닙니다. 평가 종료로 마칩니다.

08

완료·수정·재확인

평가가 종료되었습니다와 최종 평가 완료 표시를 확인합니다.

  1. 평가 창에서 완료 안내를 확인합니다. 업무 목록의 진행 상태도 평가 완료로 바뀝니다.
  2. 평가 단계가 진행 중이면 평가 수정으로 다시 편집한 뒤 평가 종료를 누릅니다.
  3. 재확인 필요가 표시되면 평가 입력을 열어 바뀐 문헌과 품질 순위를 확인하고 다시 종료합니다.
  4. 필요하면 내 심사 업무의 내 업무 자료 엑셀 저장으로 자료를 받습니다.

평가 후 새로운 AI 결과가 공개되거나 공개 문헌·보고서·서지정보·URL 또는 선행기술조사 보고서 유무가 바뀌면 재확인이 필요할 수 있습니다.

단계가 중지·마감되거나 월 전체가 마감되면 수정할 수 없습니다. 관리자에게 재개를 요청합니다.

저장 오류가 나오면 완료되지 않은 상태입니다. 입력을 유지한 채 안내를 확인하고 다시 저장합니다. 충돌 시에는 필요한 입력을 보관한 뒤 최신 자료를 불러옵니다.

화면을 누르면 확대됩니다. 각 HTML은 이미지가 포함된 파일이며, 브라우저에서 인터넷 없이도 볼 수 있습니다.
