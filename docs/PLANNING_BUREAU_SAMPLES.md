# 기획국 실제 출원 샘플

2026-10-28에 지식재산처 공식 조직도와 Google Patents 공개 원문을 확인해 샘플을 구성했습니다. `scripts/data/planning-bureau-samples.json`에 출원번호, 공보번호, 명칭, CPC, 개별 출처를 기록했습니다. 출원번호와 공개·등록공보 번호를 구분합니다. 일부 CPC는 같은 특허 패밀리의 WO 공보에서 확인했으며 별도 출처를 표시했습니다.

| 심사과 | 출원 수 |
| --- | ---: |
| 생활용품심사과 | 5 |
| 식품생물자원심사과 | 5 |
| 주거기반심사과 | 5 |
| 가전제품심사과 | 5 |

공식 과 이름과 실제 출원번호를 사용한 체험용 배치이며, 해당 출원의 실제 담당 과나 심사관을 나타내지 않습니다. 심사관 이름은 가상 계정으로 유지합니다. 새 출원에 AI 검색 결과나 평가 실적을 만들어 넣지 않으며 결과 입력 대기로 등록합니다. 샘플 업무 공간 표시(`isDemo`)는 유지하지만 실제 출원번호는 PDF를 다운로드할 수 있습니다. 원래 생성한 `10-2024-9000000`~`9000019`만 개별 PDF와 ZIP 대상에서 제외합니다.

PDF 저장본을 읽거나 저장하는 중 오류가 나면 KIPRIS에서 받은 원본을 검증한 뒤 바로 전달합니다. 이 응답은 `X-Document-Cache: BYPASS`로 구분하며 다음 요청에서 저장을 다시 시도합니다. 원본 조회 실패, PDF 형식 오류, 출원번호 불일치는 계속 차단합니다.

스크립트는 지정된 운영 사이트의 `기획국` 업무 공간과 2026년 10월 샘플만 처리합니다. 계정 10명의 소속 과와 두 샘플 그룹의 이름을 변경하고, 실제 출원 20건을 먼저 추가한 뒤 원래 생성된 `10-2024-9000000`~`9000019`만 선정 취소합니다. 기존 가상 출원의 결과·평가와 취소 이력을 보존합니다. 공지, 운영월 설정, 사용자 역할, AI 배정, 별도로 등록한 11월 출원은 변경하지 않습니다.

```powershell
# 저장할 변경 사항 미리보기 (읽기 전용)
node scripts/seed-planning-bureau.mjs

# 로컬 검증
node --experimental-strip-types scripts/test-planning-bureau-seed.mjs

# 운영 API에 반영
node scripts/seed-planning-bureau.mjs --apply
```

반영 직전에 `outputs/planning-bureau-backup-날짜.json`을 저장하고, 완료 후 같은 폴더에 검증한 응답을 저장합니다. 이 폴더는 Git에서 제외됩니다. API의 revision을 매 요청에 사용하며 충돌하면 즉시 중단합니다. 재실행하면 이미 추가한 출원과 취소한 가상 건은 건너뜁니다. 운영 계정이나 그룹으로 변경된 자료는 덮어쓰지 않습니다.
